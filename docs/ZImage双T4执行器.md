# Z-Image 双 T4 执行器

模型版本、FP32精度、提示词编码、随机种子、调度器、9步采样和PNG输出保持一致。去噪器按完整Transformer块分配到两张GPU，采样循环内权重常驻显存。分配前根据真实参数大小预留推理空间，加载后逐个核对参数的精度和所在设备。

FP32提示词编码器本身超过单张T4容量，因此仍逐层加载。每张图编码前暂时移走第一张卡上的部分去噪块，编码结束后恢复。编码仍在CUDA上运行；切换权重只发生在编码、去噪、解码的阶段边界，避免每个去噪步骤搬运整个模型。不使用量化或缓存预测结果来跳步。

大图采样结束后，将第一张卡上的部分去噪权重移回CPU，为FP32 VAE解码留出显存。下一张任务的提示词编码结束后再恢复这些权重。VAE缩放、解码与后处理保持原Pipeline算法，不缩小图片。

连续任务复用同一组模型与设备分配。只有提示词编码和图片生成需要重复执行；环境安装、模型下载和首次加载计时独立记录。运行元数据包含设备分配、两卡峰值显存、编码阶段耗时与整体生成耗时。

验证分两层：本地测试检查显存规划的边界及不足时拒绝，编译实际Notebook与子进程Python；GPU实测必须核对PNG完整解码、同参数基线的像素差和SSIM、实际耗时及会话复用。编译或模型加载完成不能代替真实出图验收。
