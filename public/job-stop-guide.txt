H3 任务停止说明

新任务：任务卡片点击“停止任务”，确认后发送停止请求。任务保持“正在停止”，直到 Kaggle 状态接口确认结束，才变为“已停止”并释放账户占用。刷新或关闭网页不会撤销停止请求。已使用的 GPU 时间不会退回。

实现：保存 Kaggle 明确返回的运行会话 ID；Notebook 版本号、Notebook ID 不用作运行会话 ID。没有返回会话 ID时，新 Notebook 会读取仅属于本任务的停止信号，在收到请求后结束生成进程。网络故障或运行环境卡死可能延迟停止；可在 Kaggle 页面直接停止。

历史任务：此功能发布前提交的 Notebook 没有停止信号监听器。如未保存运行会话 ID，任务卡片显示“前往 Kaggle 停止”。系统不会因为本地标记而假称远端已停止，也不会通过重新提交覆盖运行中的任务。

安全：站点停止接口仍要求原访问密码会话。Notebook 中的任务控制凭证仅能读取对应任务的停止信号，不能读取账户密钥、视频、其他任务或发送停止请求。数据库只保存控制凭证摘要。Kaggle 账户密钥仍仅在服务器加密保存。

在 Kaggle 后台手动停止或删除后：点击任务卡片“已在 Kaggle 结束”并确认。此操作只更新工作室残留状态，保留历史参数，释放账户占用；记录注明“用户确认在 Kaggle 后台结束”，不会声称由 API 确认远端停止。正在执行的同步不会把这条记录恢复成运行中。
